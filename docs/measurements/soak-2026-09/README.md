## Что нужно знать, прежде чем что-то из них считать

**Два столбца размера — намеренно.** `df_used_kb` и `apparent_kb` расходятся by design: `MAPPED`
создаёт разреженный файл во всю ёмкость сегмента. Утверждение «том вышел на полку» без указания,
о какой из двух величин речь, не значит ничего.

**`consumed ≈ produced / 2` — форма стенда, а не потеря.** Потребитель читает только партицию 0.

**Первая строка `samples.csv` — с `-1` в счётчиках.** Метрики на нулевой секунде ещё не отвечали.
Это единственная ненулевая строка за весь прогон, и она про инструмент, а не про брокер.

**`memory.csv` и `regions.csv` начинаются позже `samples.csv`.** Сэмплеры памяти и регионов заведены
по ходу прогона — когда `RssAnon` показал линейный рост и потребовалось приписать его месту,
а не времени. Ответ оказался «куча дошла до `-Xmx64M`», и он виден в `regions.csv` как единственный
двигающийся регион `fc000000`.

**Строка `after 35 s of sampling` в `finished.txt` неверна.** `finish.sh` считает `now - mtime`
файла выборок, то есть время с последней записи, а не длительность. Настоящее окно — из самих рядов.

## `stand/`

Скрипты, которыми это снято, и эксперименты, сделанные после останова на том же логе:

| | |
|---|---|
| `up.sh` | поднимает стенд: loop-образ на 2 ГиБ, брокер, нагрузка, сэмплер |
| `sample.sh`, `mem.sh`, `regions.sh` | три сэмплера, три файла — **каждый отдельным файлом намеренно**: правка скрипта, который прямо сейчас исполняется, портит его |
| `finish.sh` | останов по таймеру: гасит нагрузку и сэмплеры, брокер и том оставляет стоять |
| `fill.sh` | добивание тома: полевая проверка issue #15 на состаренном логе |
| `ab.sh`, `after.sh`, `proof.sh` | 0.3.0 против 0.3.1 на одном и том же полном томе; что бывает после освобождения места; старый и новый питон-клиент на одном отказе |
| `recovery.py`, `half.py` | кривая восстановления: 0 / 16 / 32 сегмента, варианты чередуются, кэш вытесняется пофайлово через `posix_fadvise` — на коробке рядом k0s, и глобальный сброс мерил бы соседей |

Стенд был **loop-образом фиксированного размера**, и это главное решение, а не деталь: рядом k0s,
и забивать коробке диск нельзя ни при каком свободном месте.
